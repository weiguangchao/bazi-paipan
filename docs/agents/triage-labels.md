# Triage Labels

本技能以五个规范 triage 角色表述，本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| Label in mattpocock/skills | Label in our tracker | 含义                                     |
| -------------------------- | -------------------- | --------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需维护者评估该 issue                       |
| `needs-info`               | `needs-info`         | 等待上报者补充更多信息                      |
| `ready-for-agent`          | `ready-for-agent`    | 已完整规设，可供 AFK agent 实施             |
| `ready-for-human`          | `ready-for-human`    | 需人工实现                                |
| `wontfix`                  | `wontfix`            | 不会处理                                  |

当技能提及某角色（如"apply the AFK-ready triage label"），按此表取对应 label 字符串使用。

需要时编辑右栏以贴合你实际使用的词汇表。
