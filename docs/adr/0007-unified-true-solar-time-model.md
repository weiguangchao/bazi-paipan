# 统一四柱、起运、当前大运与流月的真太阳时时间模型

用户提交的 `Birth Data` 继续表达钟表时与可选出生地。完整命盘入口是唯一时间转换边界：它解析出生地经度，把出生时刻、一次注入的当前钟表时、立春及所需 `Jie` 分别转换到同一出生地的真太阳时。后续四柱、子正、起运、当前大运与流月定位只使用这些真太阳时读数。生肖、星座、流年序列与“今年”继续保持原始公历语义。

`TrueSolarDateTime` 是只含年、月、日、时、分、秒和整数毫秒的纯时间值，不携带经度修正是否应用等计算状态。经度修正与每个事件自身时刻的寿星均时差在完整浮点精度下合成，只在构造该值时四舍五入一次到最近毫秒。未提供出生地时，出生时刻沿用钟表时字段并补零毫秒，交节也沿用默认钟表时语义。

年柱以出生真太阳时与真太阳时立春比较，月柱以出生真太阳时定位十二个真太阳时 `Jie` 区间；交节前属于旧柱，交节当毫秒及以后属于新柱。日柱以真太阳时子正为日界；时柱、早晚子时和近子正读取同一个出生真太阳时。

大运方向继续使用阳男阴女顺、阴男阳女逆。顺行取严格晚于出生真太阳时的第一个 `Jie`，逆行取严格早于出生真太阳时的第一个 `Jie`，重合交节不作为目标。起运间隔由两个真太阳时读数求差，第一步大运的起运年月以出生真太阳时年月为基准。当前大运以命盘出生地的当前真太阳时年月定位。

流月从真太阳时立春延续到下一年真太阳时立春前，每个边界分别使用该 `Jie` 自身的均时差换算；“本月”与交节日期来自同一组真太阳时边界。

ADR-0006 的固定寿星版本、最小太阳核心、同步无状态无缓存、独立 JPL/HKO oracle、1801—2099 正式范围、性能与 bundle 门禁继续有效。本决议只修订其北京时间交节、整秒时间值及据此形成的排盘时间模型，不改写其历史记录。
