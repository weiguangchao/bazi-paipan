# 五行展示配色与 emoji 第二信号

四柱与大运的五行展示从“仅文字色相”改为“分区信号”：四柱天干/地支用五行颜色 + 五行 emoji（木🪵 火🔥 土⛰️ 金🪙 水💧），藏干仅用五行颜色，大运/流年干支既不用颜色也不用 emoji，只显前景墨色。十神仍用简写。

配色重选：旧木=green-600、火=red-600、土=amber-700、金=orange-600、水=blue-500，其中 amber-700(#b45309) 与 orange-600(#c2410c) 色相差约 8°，与火 red-600(#dc2626) 同处红橙暖簇，在暖奶白底(oklch 0.968 0.005 80) 上金/土/火区分不明显。新取木=emerald-700、火=rose-700、土=yellow-700、金=slate-600、水=blue-600：金推冷灰、土推金黄，冷暖两极分开；五色对奶白底 WCAG 对比均 ≥ 4.5，藏干 text-sm 小字也达正文 AA。对比度由 test/wuxing-colors.test.ts 守卫，防回退。

被否的是三档备选：(1) 仅改色相不加 emoji——色相在暖底上始终被压缩，藏干小字辨识仍弱；(2) 色相加淡同色背景块（B 方案）——引入第二维亮度信号但视觉重量过大；(3) 左侧色条加墨色字符（C 方案）——对色弱友好但改动大、需重排大运紧凑行。最终取“色相 + emoji”是因为 emoji 提供颜色之外独立、可图形化直读的第二信号，比文字“木火土金水”更直观，且不增加背景层、不改布局；emoji 仅用在四柱干支而非全场景，避免大运卡片视觉过载。

emoji 表意取舍：金选 🪙（金币，金色 + 直指金属/金本义，与 slate-600 冷灰字形成反差），否决 🔩/⚙️/⛓️（灰金属与灰字同向糊成一片，或带机制/链条隐喻）和 🥇/💍（带竞技/饰物隐喻，与命理语境不搭）。木🪵 火🔥 土⛰️ 水💧 沿用表意清晰的常见图样。

被否的还有恢复旧实现的全 emoji 方案（2628544 之前的天干/地支/藏干皆 emoji）：藏干列密集，emoji 会撑乱排列，且藏干已有五行颜色足够。大运/流年去色去 emoji 是显式取舍：大运卡片信息密度高，五行色 + emoji 会让每张卡过载，且大运的阅读重点是十神与起运而非五行归属，故降为纯墨色。
