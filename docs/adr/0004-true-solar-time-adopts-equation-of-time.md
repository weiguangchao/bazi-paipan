# 真太阳时采纳均时差（视太阳时）

排盘的真太阳时取视太阳时：钟表时先按出生地经度做经度修正得平太阳时，再按出生 UTC 日期加均时差得视太阳时，所有柱从视太阳时算起（真太阳时 = 平太阳时 + 均时差）。均时差用 NOAA 简化式自实现、纯函数、按出生 UTC 时刻求值，不引入第三方天文库。未给出生地时仍走钟表时，行为不变。

选视太阳时是命理正统，也是问真八字等主流排盘的默认行为，用户拿结果对照主流排盘能对得上。被否的是平太阳时派（仅经度修正、不含均时差）：同一钟表时刻算出的真太阳时系统性偏移最多约 ±16 分（2 月中 −14 分、11 月初 +16 分），会在均时差极值日期排错时辰，乃至近子正时排错日柱，与主流排盘/传统不一致。
