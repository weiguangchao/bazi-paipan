# 以寿星太阳核心统一节与真太阳时计算

排盘以寿星天文历仓库固定提交 `c55a3f62b2831887066340e0b80a5fd0ef6f15e1` 为唯一生产天文算法来源，明确归属寿星天文历与许剑伟；只忠实移植太阳坐标、太阳视黄经反求时刻、章动、光行差、ΔT、儒略日转换与高精度时差 `pty_zty` 的最小依赖闭包，公式和数据不作语义修改。月球、定朔、农历、古历兼容算法、预生成生产表与第三方天文运行时均不进入产品。JPL/Horizons 与香港天文台数据只作为独立验收依据，不能被生产代码导入。

寿星底层是无状态、同步、无缓存的私有深 module，不向排盘暴露 TT、UT、UTC、儒略日、星历数组或底层计算函数。领域层只通过两个窄 facade 使用它：十二个强类型 `Jie` 的交节计算，以及经度修正与寿星均时差合成的真太阳时计算；不公开二十四节气数字索引。`BeijingDateTime` 与 `TrueSolarDateTime` 均由年月日时分秒构成，不含毫秒。寿星内部保留完整浮点精度，交节时刻在 facade 出口四舍五入到最近整秒；真太阳时先以完整精度合并经度修正与均时差，最后只取整一次。未提供出生地时，`TrueSolarDateTime` 直接复制 `BeijingDateTime` 的字段。

年柱、月柱与起运间隔以出生北京时间和北京时间交节时刻计算，使同一绝对时刻不因出生地经度不同而跨越年、月边界；日柱、时柱、早晚子时与近子正判断使用真太阳时。这取代 ADR-0004 中 NOAA 简化均时差以及“所有柱从真太阳时算起”的决定，但保留“真太阳时 = 平太阳时 + 均时差”的领域定义。正式支持范围固定为 1801-01-01 至 2099-12-31，范围外明确拒绝。

实施采用彻底替换而非兼容双轨：删除旧 `ShouXingUtil`、NOAA 均时差、UTC 领域字段、八小时补偿、数字节气索引与兼容 re-export。验收同时要求固定寿星版本全量差分和 JPL/HKO 独立验证；全量 3588 个 `Jie` 在整秒出口与寿星完全一致，均时差差分不超过 0.01 秒，JPL 均时差不超过 1 秒，HKO 分钟表不超过 60 秒。JPL 交节原定 3 秒阈值在扩展到 1801—2099 端点后不再适用：固定寿星版本在 2099 大雪样本的实测偏差为 113.154 秒，经明确决定继续采用寿星算法并将独立 JPL 交节门禁调整为 120 秒；这只改变外部验收阈值，不改变寿星全量整秒一致性要求。交节前一秒属旧柱，交节当秒及后一秒属新柱。同步完整命盘首次计算不超过 100 ms、连续 50 次 p95 不超过 50 ms，主 JS chunk 小于重构前 540.42 KB 并消除超过 500 KB 的构建警告；不得以缓存、预生成生产表、异步加载或降低精度规避失败。
