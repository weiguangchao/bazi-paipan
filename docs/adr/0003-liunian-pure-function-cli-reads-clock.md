# 流年独立纯函数，排盘不读时钟

流年 = "今年起向后 10 柱干支"，由独立纯函数 `流年(今年公历年)` 产出，不注入 `排盘Input`、不进 `排盘Result`。"今天"由 CLI 边缘按北京时间（UTC+8）读机器时钟算出今年公历年再传入。`排盘` 核心保持无时钟、纯函数不变。

流年只依赖"今年"而不依赖出生数据，塞进 `排盘` 是硬凑耦合；且让 `排盘` 读 `Date.now()` 会破坏其纯度，使现有 5 个测试文件变成跨年时间炸弹。被否的两套：把 `参考时刻` 注入 `排盘Input`（A，让 `排盘` 背一个它不需要的参数并改所有现有测试）、`排盘` 内部直接 `new Date()`（B，直接牺牲纯度与测试稳定性）。
